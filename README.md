**Professional Manual Camera App** is an enthusiast mobile photography suite bringing manual DSLR-grade controls to mobile devices. It unlocks manual exposure compensation, granular ISO tuning, custom shutter speeds, focus peaking, and uncompressed DNG RAW image capture.

---

## 🌟 Capabilities

- **Manual Exposure Control**: Adjust ISO (50-3200), shutter speeds (1/8000s to 30s), and EV bias in real-time.
- **RAW DNG Capture**: Save uncompressed sensor sensor data preserving full dynamic range for post-processing in Lightroom.
- **Live Focus Peaking**: Visual neon highlights overlaying in-focus focal planes.
- **Histogram & Zebra Stripes**: Real-time luminance histogram preventing clipped highlights and crushed shadows.
